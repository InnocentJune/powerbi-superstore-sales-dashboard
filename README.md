# powerbi-superstore-sales-dashboard
Interactive Power BI dashboard analyzing Superstore sales, profit, customer segments, and regional performance.
Superstore Sales Performance Dashboard (Power BI)

This project is an interactive Power BI dashboard built using the Sample Superstore dataset. The dashboard provides insights into sales performance, profitability, customer segments, product categories, shipping modes, and regional trends.

Key Features
Sales, Profit, Orders, and Profit Margin KPIs
Regional Sales and Profit Analysis
Segment Performance Comparison
Category-wise Sales Distribution
Shipping Mode Profitability Analysis
State-level Sales Performance
Product-level Sales and Profit Analysis
Dynamic filtering using slicers
Key Insights
The West region generated the highest sales and profit.
Consumer segment contributed the most profit.
Standard Class shipping produced the highest profit.
Technology category recorded strong sales performance.
California was the leading state in total sales.
Tools Used
Power BI Desktop
DAX Measures
Data Modeling
Data Visualization
Interactive Slicers and Filters
